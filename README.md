# Joao Graça — Portfolio

Personal portfolio website showcasing my projects and work as a Front-End Developer.

🔗 Live Demo: [joaograca.dev](https://joaograca.dev)

## 🌐 Portfolio Website

A modern developer portfolio built with Astro and Tailwind CSS.
It showcases my projects with a fast, responsive, and minimalist design.

## ✨ Features

- ⚡ Built with Astro for fast performance
- 🎨 Styled using Tailwind CSS
- 📱 Fully responsive design
- 🧩 Component-based structure
- 🚀 Optimized for SEO and performance

## 🛠️ Tech Stack

- Astro
- Tailwind CSS
- TypeScript

## 🚀 Getting Started

Clone the repository:

git clone https://gitlab.com/jcggraca/portfolio.git  
cd portfolio

Install dependencies:

`npm install`

Run the development server:

`npm run dev`

## 📦 Build

Create a production build:

`npm run build`

Preview locally:

`npm run preview`
